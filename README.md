## Оживаляющий бот для Telegram

___
### Описание работы

Бот принимает фото от пользователя и **оживляет его** с помощью
сервиса Cutout.pro. Затем отправляет ответ в чат в виде видео-файла

___
### Особенности работы

* В боте реализованы команды `/start`и `/help` (help можно писать без слэша)
* При невозможности обработки фото бот **Выводит сообщение об ошибке и её описание** 
* Если все прошло удачно отпраляет видео-файл и сообщение **Ваше «живое» фото**

___
### Запуск

Для тестирования в боте реализовано логгирование с помощью Loguru  

В корневой папке проекта должен находится файл `.env`, в нём должен выть записан токен бота и токен Cutout.pro  
в формате (**обратите внимание без кавычек и пробелов**):

`BOT_TOKEN=токен вашего телеграм бота`  
`API_KEY=токен выдаваеемый Cutout.pro`

___
### Технологии

Для реализации использовалися модуль request м платформа aiogram 3.x
